# ROM5 — unsupported slot (no image)

No recovered ROM5 program image exists, and no ROM5-range block table
has been observed in local images (8210 v5.11/v5.29/v5.31 tables are
all ROM6-range — including both halves of the dual sets). The
8210→ROM5 link is user-reported. Same landing checklist as
[ROM3](../rom3/README.md): geometry, SHA-256 in doc 03, `verify` +
`disasm` support, `roms/rom6/` mirror, and a fingerprint range that
falls outside both known bands.
